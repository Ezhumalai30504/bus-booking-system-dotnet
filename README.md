# 🚌 Bus Booking System (.NET Full Stack)

This is a full-stack Bus Booking System developed using ASP.NET Core Web API and ASP.NET Core MVC.
---
## 🚀 Features

### 👤 User
- Register & Login
- Email OTP Verification
- View available routes
- Book seats
- View booking history

### 🛠 Admin
- Manage buses and routes
- View bookings
- Control system data

---

## 🔐 Authentication

- JWT Token-based authentication
- Role-based authorization (Admin/User)
- Secure API endpoints
---
## 🛠 Technologies Used

### Backend (API)
- ASP.NET Core Web API
- Entity Framework Core (Code First)
- SQL Server
- JWT Authentication

### Frontend (MVC)
- ASP.NET Core MVC
- C#
- HTML, CSS, JavaScript

---

## 🔗 Architecture

- MVC (Frontend) communicates with Web API (Backend)
- API handles business logic and database operations
- JWT token used for secure communication
